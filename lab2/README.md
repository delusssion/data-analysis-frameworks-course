# Лабораторная работа №2

## Временные ряды

## Цель

Восстановить аккуратный согласованный датафрейм из вручную отредактированного Excel-файла с погодными временными рядами, провести анализ ряда и построить модели для многошагового прогноза температуры на одну неделю вперёд (горизонт 168 часов).

## Что сделано в работе

В ноутбуке выполнены основные этапы работы:

1. Получен доступ ко всем листам Excel-файла с помощью `openpyxl` и `pandas`, в том числе к двум скрытым листам.
2. Данные очищены и унифицированы: исправлен моджибейк (cp1251, прочитанный как latin-1), нормализованы названия городов, восстановлен «съехавший» вправо блок на втором листе, листы объединены в один датафрейм, построен единый почасовой индекс, обработаны строковые NaN-сентинелы и кириллические категории в числовых колонках, физические границы и локальный MAD-фильтр устранили выбросы, пропуски заполнены интерполяцией.
3. Проведён анализ временного ряда: визуализация температуры на разных частотах, средние профили по часу и месяцу, STL-декомпозиция на тренд/сезонность/остатки, ACF/PACF, тесты стационарности ADF и KPSS, FFT, STFT-спектрограмма, вейвлет-скалограмма (CWT с вейвлетом Morlet).
4. Извлечены признаки для прогнозирования: лаги целевой переменной (1, 2, 3, 6, 12, 24, 48, 72, 168, 336 ч), лаги экзогенных переменных, скользящие статистики `mean`/`std`/`min`/`max` по окнам 6/24/168 ч, циклические календарные признаки через `sin`/`cos`, one-hot кодирование города. Построены отдельные выборки под recursive- и direct-стратегии, выполнено хронологическое разбиение `train`/`val`/`test`.
5. Построены `DecisionTreeRegressor`, `RandomForestRegressor`, `HistGradientBoostingRegressor`. Гиперпараметры подобраны через `Optuna` с expanding time-series cross-validation. Сравнены recursive-стратегия и direct-стратегия с отдельной моделью на каждый шаг недельного прогноза.
6. Оценено качество прогноза на тестовом отрезке: лучшая по валидации комбинация (HGB + direct) дообучена на `train + val`, рассчитаны WAPE, MAE, MAPE, directional accuracy, directional R²; построены графики MAE по горизонту, прогнозов и анализа остатков.

## Установка зависимостей

### Вариант 1: через `pip`

```bash
cd lab2
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

Если нужен отдельный kernel для Jupyter:

```bash
python -m ipykernel install --user --name time-series-lab2
```

### Вариант 2: через `uv`

```bash
cd lab2
uv venv
uv sync
```

Если нужен отдельный kernel для Jupyter:

```bash
uv run python -m ipykernel install --user --name time-series-lab2
```

## Запуск ноутбука

После установки через `pip`:

```bash
jupyter notebook
```

После установки через `uv`:

```bash
uv run jupyter notebook
```

Затем нужно открыть [notebook.ipynb](./notebook.ipynb).
